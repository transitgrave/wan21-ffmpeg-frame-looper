# WAN2.1 FFmpeg Frame Looper
Frame extractor for WAN2.1 FLF2V
This ComfyUI custom node extracts the first or last frame of a video using `ffmpeg` and loads it into the ComfyUI pipeline as an image. Perfect for creating loopable video transitions with the WAN2.1 model.
